# My VSIX

自分の VS Code（や Kiro）で毎日使える「自分用の小さな拡張機能」を、AI と一緒に 60 分で作るためのキットです。

<img src="assets/illustrations/desk.webp" width="420" alt="窓辺の小さな作業机">

## これは何か

- 対象: GitHub Copilot のライセンスが配られている方（Kiro でも使えます）
- できること: 日常の小さな困ったことを1つ解消する拡張を、課題の言語化から「自分のエディタで動く」ところまで体験できます
- 作るものは3つの型のどれかです（コマンド型／表示型／パネル型）。詳細は [型カタログ](catalog/types.md)
- 完成したものは **自分が使うためのもの** です。Marketplace などへの公開はこのキットの範囲に含みません

## はじめ方

全体の流れは [はじめ方ガイド](docs/getting-started.md) にあります。

1. [事前準備ガイド](docs/pre-setup-guide.md) を読んで、事前準備（Python と pre-commit の用意）を済ませる
2. AI（Copilot／Kiro）のチャット欄に、次の文をそのまま入力する（このスキルだけは最初から読み込める場所に置いてあります）

   ```
   my-vsix-setup スキルで進めて
   ```
3. あとは AI の案内に沿って進めるだけです。本編の目安は60分です

## 安全のための約束（ガード）

- 作品は自分のパソコンの中だけで動きます。外部へ通信する機能は作れません
- 作品に入れる部品は追加しません（依存ゼロ）。鍵やトークンを作品に埋め込むこともできません
- ビルドの入口で機械チェックが走り、約束に反するものは VSIX になりません

## 困ったら

- まず [FAQ](docs/faq.md) を見るか、AI のチャット欄に `my-vsix-help スキルで進めて` と入力してみてください
- それでも解決しない場合は、利用者同士の場 → キットの Issue の順に相談してください
