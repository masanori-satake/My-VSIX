# 事前準備ガイド

体験会や自習の **当日ではなく、事前に** 終わらせておくためのガイドです。
当日にここで待つと、本編の60分が待ち時間で消えてしまいます。

## 用意するもの（システム側はこの2つだけ）

1. Python（動作保証範囲のバージョン。版数はキット初版の実測後に確定します）
2. pre-commit

Node.js は **不要** です。ビルドに必要な道具は、pre-commit が管理する隔離環境の中に自動で用意されます。

## 手順（1ステップずつ）

### ステップ1: Python の確認

```
python --version
```

保証範囲のバージョンが表示されればOKです。表示されない・範囲外の場合は、案内された入手先から入れ直してください。

### ステップ2: pre-commit の確認

```
pre-commit --version
```

バージョンが表示されればOKです。

### ステップ3: フックの導入と初回実行

キットのフォルダで次を実行します（初回は道具のダウンロードがあるため時間がかかります）。

```
pre-commit install -f
pre-commit run --all-files
```

## 動作確認基準（全部に当てはまれば準備完了）

- [] `python --version` で保証範囲内のバージョンが表示される
- [] `pre-commit --version` でバージョンが表示される
- [] `pre-commit run --all-files` が最後まで実行できる（初回ダウンロードが終わっている）
- [] AI ツール（Copilot／Kiro）で my-vsix-setup スキルが認識されている

## キットをやめるとき

pre-commit のキャッシュを消すと隔離環境は残りません。作品ごとに作ったフォルダと、エディタ側の拡張を削除すれば元通りです。
