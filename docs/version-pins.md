# バージョン固定表

キットが前提とするバージョンの一覧です。セットアップやビルドはこの表の範囲で動作させます。数値は「実測日」時点の公開情報とレジストリで確認したものです。

- 実測日: 2026-11-08
- 確認方法: PyPI／npm レジストリの最新版照会、Node.js 公式の配布一覧、Kiro の公開情報（変更履歴の解説）

| 対象 | 固定・保証範囲 | 根拠と備考 |
|---|---|---|
| Python | **3.10〜3.13 を保証範囲**（実測 3.12.3） | pre-commit 4.x の動作要件（3.10 以上）に合わせる。キットのスクリプトは標準ライブラリのみで、この範囲で動く書き方に限定する |
| pre-commit | **4.7.0**（実測時点の最新） | PyPI で確認。事前準備ではこの版の導入を案内する |
| Node.js | **24 LTS 系**（実測 24.22.1） | システムには入れない。pre-commit の隔離環境が自動調達する前提の版。vsce 4.x の動作要件（Node 22 以上）を満たす LTS を選んだ |
| vsce（@vscode/vsce） | **4.1.0**（実測時点の最新） | npm レジストリで確認。隔離環境にのみ入れる。実際のパッケージング動作の確認は、ビルド入口の実体化時に行う |
| 対象エディタの下限（engines.vscode） | **^1.100.0** | Kiro の土台は Code OSS で、Kiro 1.0.x 系は 1.109.5、1.1（2026-09）で 1.131 に上がったことが公開情報で確認できる。職場で旧めの Kiro が残っていても届くよう、キットが使う API（コマンド登録、ステータスバー、Webview、一覧からの選択はいずれもずっと前から安定している）の範囲で下限を 1.100 に置く |

## 注意
- 職場の実環境（利用中の VS Code／Kiro の版）での最終確認は未実施です。体験会の前に、参加者の環境の版がこの範囲に入っているかを事前準備ガイドの動作確認基準で確かめてください
- Kiro の土台が大きく上がった場合は、この表とテンプレートの `engines.vscode` を合わせて見直します

## 更新の手順
1. この表の数値を実測し直す（レジストリ照会と Kiro の公開情報）
2. テンプレート3型の `package.json` の `engines.vscode` を合わせる
3. 事前準備ガイドの案内（Python／pre-commit の版）に影響があれば直す
