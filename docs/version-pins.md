# バージョン固定表

キットが前提とするバージョンの一覧です。セットアップやビルドはこの表の範囲で動作させます。数値は「実測日」時点の公開情報とレジストリで確認したものです。

- 実測日: 2026-11-08
- 確認方法: PyPI／npm レジストリの最新版照会、Node.js 公式の配布一覧、Kiro の公開情報（変更履歴の解説）

| 対象 | 固定・保証範囲 | 根拠と備考 |
|---|---|---|
| Python | **3.11〜3.14 を保証範囲**（実測 3.12.3） | 保証範囲は「サポート終了（EOL）になっていない版」だけにする。3.10 は 2026-10 に EOL を迎えたため範囲外（範囲に入れると推奨しているように見えるため）。キットのスクリプトは標準ライブラリのみで、この範囲で動く書き方に限定する。EOL の予定は毎年ずれるので、版の見直し時に範囲も見直す |
| pre-commit | **4.7.0**（実測時点の最新） | PyPI で確認。事前準備ではこの版の導入を案内する |
| Node.js | **24 LTS 系**（実測 24.22.1） | システムには入れない。pre-commit の仮想環境が自動調達する前提の版。vsce 4.x の動作要件（Node 22 以上）を満たす LTS を選んだ |
| vsce（@vscode/vsce） | **4.1.0**（実測時点の最新） | npm レジストリで確認。仮想環境にのみ入れる。実際のパッケージング動作の確認は、ビルド入口の実体化時に行う |
| 対象エディタの下限（engines.vscode） | **^1.100.0** | Kiro の土台は Code OSS で、Kiro 1.0.x 系は 1.109.5、1.1（2026-09）で 1.131 に上がったことが公開情報で確認できる。古めの Kiro を使っている環境でも使えるよう、キットが使う API（コマンド登録、ステータスバー、Webview、一覧からの選択はいずれもずっと前から安定している）の範囲で下限を 1.100 に置く |

## 実機の確認状況
- 2026-11-08、キット作者の手元の Kiro で確認: **Kiro 1.4.121（土台の版 1.131.0）**。下限 ^1.100.0 の範囲に収まっている

## 注意
- 参加者の環境（利用中の VS Code／Kiro の版）での確認は未実施です。体験会の前に、参加者の環境の版がこの範囲に入っているかを事前準備ガイドの動作確認基準で確かめてください
- Kiro の土台が大きく上がった場合は、この表とテンプレートの `engines.vscode` を合わせて見直します
