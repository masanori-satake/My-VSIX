# 体験会ガイド

## 目的

60分で「動いた」と「見せ合う」まで到達し、「何だ、簡単なんだ」「自分にもできた」を持ち帰ってもらう点火の場です。

## 進め方

- お題は型ごとに3つ用意されています（`workshop/` フォルダ）。参加者は型（表示型／コマンド型／魅せるパネル型）を選びます
- 開始前に、事前準備ガイドの動作確認基準を全員が満たしていることを確認してから、本編の時計を始めます
- 本編の時間配分は通常のフェーズ別配分（言語化の短縮版5分／型とカスタマイズ5分／実装20分／ビルド・検証10分／お披露目・見せ合い15分／予備5分）を目安にします
- 締めは全員の完成サマリとスクリーンショットを並べて見せ合います
- 出口では「次は自分の課題で作れる」ことを案内します（入口は my-vsix-problem）

## 開催者の負担を増やさないために

- お題は開催のたびに選び直しません。キット同梱のお題パックを使います
- 体験会後の質問は通常のサポート3段（FAQとスキル → 利用者同士の場 → キットの Issue）に合流させます
