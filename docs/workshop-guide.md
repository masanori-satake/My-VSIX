# 体験会ガイド

## 目的

60分で「動いた」と「見せ合う」まで到達し、「何だ、簡単なんだ」「自分にもできた」という体験を持って帰る場です。

## 進め方

- お題は型ごとに3つ用意されています（`workshop/` フォルダ）。参加者は型（表示型／コマンド型／パネル型）を選びます
- 開始前に、事前準備ガイドの動作確認基準を全員が満たしていることを確認してから、スタートしてください
- 本編の時間配分は通常のフェーズ別配分とし、以下を目安とします
  - 言語化の短縮版: 5分
  - 型とカスタマイズ: 5分
  - 実装: 20分
  - ビルド・検証: 10分
  - お披露目・見せ合い: 15分
  - 予備: 5分
- 締めは全員の完成サマリとスクリーンショットを並べて見せ合います
- 会の終わりでは、「次は自分の課題で作れる」ことを案内します。使うのは my-vsix-problem スキルで、チャット欄に次の文を貼って始めます

  ```
  my-vsix-problem スキルで進めて
  ```

## 開催者の負担を増やさないために

- お題は開催のたびに選び直しません。キット同梱のお題パックを使います
- 体験会後の質問は、開催者への個別質問にせず、通常の相談の流れ（FAQ とスキル → 利用者同士の場 → キットの Issue）に乗せます
