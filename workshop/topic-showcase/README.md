# 魅せるパネル型お題パック: 自分専用チートシート

## 狙い
自分がよく忘れるコマンド・手順・覚え書きを、自分の言葉で書いて大きく眺める道具。「自分の脳の外部拡張」を開く満足と、見せ合いのときの中身の違いが話題になる。

## 課題文（用意済み）
滅多に使わないコマンドや手順は、そのたびに検索したり過去のメモを探したりしている。自分の言葉で書いた忘れ物帳が、エディタの中に大きく開けたら探す手間が消えるのに。

## 参加者が足す一言（個人化）
自分が一番よく忘れるものを一言で足す（例: 「Git の取り消し方を毎回調べる」）。これが制作メモの課題文になる。

## 使うもの
- テンプレート: `templates/showcase/`（同梱の `cheat-sheet.json` をカード表示する。読み取り専用・ローカルのみ）
- 中身はデータファイルに自分の言葉で書く。リンクは文字列として表示するだけ（クリックで外部を開く仕組みは作らない）

## カスタマイズポイント（参加者が選ぶ）
- カードの中身 **3枚**: よく忘れるコマンド／手順メモ／自分の覚え書き、から自分の言葉で書く
- 見出しと並び順
- 色味: 枠と背景の色プリセットから選ぶ

## 実装の要点（スキル向け）
- テンプレートの器の範囲で実装する。カードの増減はデータファイルの編集で対応する
- 華（名前・アイコン・色）は make のプレビューで決める。プレビューは静的なモックで見せる

## 成功条件
コマンドでパネルが開き、自分の3枚のカードが見える。これを本人の操作で確認できたら成功。

## 詰まりやすい点
- 中身を書くのに時間が溶ける → 3枚に限定し、「あとで直せる」を先に伝える。体験会では中身の完成度は競わない
- 文字が小さい・読みにくい → プリセットの範囲で文字サイズと色味を調整する

## 見せ合いのポイント
「何を忘れるか」が人柄そのもの。3枚の中身を並べると、その人の仕事の癖が見えて一番盛り上がる。
