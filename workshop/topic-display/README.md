# 表示型お題パック: 自分のマーカー残数

## 狙い
「自分の『あとでやる』が何件残っているか、いつも見える」道具。下の帯（ステータスバー）に、自分で決めた目印の残数が常に出続け、消していく快感が自己満足につながる。作った後も毎日目に入る。

## 課題文（用意済み）
コードの中に「あとで直す」「あとで確認する」の目印を書くけれど、書いたまま忘れて残り続ける。いま開いているファイルに、あと何件残っているかがいつも見えていたら、片付け忘れが減るのに。

## 参加者が足す一言（個人化）
自分の日常の一場面に結びつける一言を課題文に足す（例: 「レビューの前に必ず見直すので」）。これが制作メモの課題文になる。

## 使うもの
- テンプレート: `templates/display/`（今開いているファイル内の目印を数えて下の帯に表示する）
- 数える範囲は **今開いているファイル** に固定する（フォルダ全体は発展形。60分で成功させるため今回は対象外）

## カスタマイズポイント（参加者が選ぶ）
- 目印の言葉: 初期値は TODO。自分のタグ（自分の名前、FIXME、あとで、要確認 など）に変える
- アイコン: 帯に出る小さな絵柄を数種類から選ぶ
- 前置きの文言: 「残り」「あと」など、数の前に付ける自分の言葉
- 0件のときの表示: そのまま「0」にするか、専用の文言（例: 「片付いた！」）にするか

## 実装の要点（スキル向け）
- テンプレートの範囲で実装する。設定は `myWork.marker` を使う
- 華（名前・アイコン・色）は make のプレビューで決める。プレビューは帯を模したイメージで見せる

## 成功条件
ファイルを開き、目印を書くと帯の数が増え、消すと減る。0件で選んだ表示になる。これを本人の操作で確認できたら成功。

## 詰まりやすい点
- 帯の表示位置が他の拡張と重なって見えにくい → 位置（左右）と優先度の調整で逃がす
- 目印の数え方（部分一致）の期待違い → 数えるのは「その言葉を含む箇所の数」と先に一言添える

## 見せ合いのポイント
目印の言葉の選び方と、0件表示の文言が人それぞれで一番違う。そこを見せ合う。
