# コマンド型お題パック: 自分の定型句ワンタッチ挿入

## 狙い
自分が何度も入力する決まり文句を、コマンド一発でカーソル位置に入れる道具。定型句の中身そのものが、その人の口癖・仕事の型であり、作品の個性になる。日常の入力がそのまま減る。

## 課題文（用意済み）
レビューのコメント、進捗の報告文、決まった挨拶など、同じ文を日に何度も入力している。コピー元を探して貼る手間も地味にかかる。自分の定型句が一発で出てきたら楽なのに。

## 参加者が足す一言（個人化）
自分の定型句が一番よく出てくる場面を一言で足す（例: 「コードレビューの返事で」）。これが制作メモの課題文になる。

## 使うもの
- テンプレート: `templates/command/`（定型句の一覧から選んでカーソル位置に挿入する）
- 定型句は設定（`myWork.phrases`）に配列で持つ。登録方式は設定に固定する（画面で編集する仕組みは発展形）

## カスタマイズポイント（参加者が選ぶ）
- 定型句の中身 **3つ**: 参加者自身が普段打っている文を持ってくる（レビュー定型／報告文／挨拶や締めの文など）。これが作品の本体
- コマンドの名前（作品の名前）: コマンドパレットに出る呼び名を自分の言葉にする

## 実装の要点（スキル向け）
- テンプレートの範囲で実装する。複数ある場合は一覧から選ぶ方式（QuickPick）のまま
- 日付やファイル名の差し込みは発展形として今回は対象外（いつかリストへ）
- 華（名前・アイコン・色）は make のプレビューで決める。プレビューは入力→出力の Before／After で見せる

## 成功条件
コマンドを実行し、選んだ定型句がカーソル位置に挿入される。これを本人の操作で確認できたら成功。

## 詰まりやすい点
- 定型句に改行や記号が多くて設定に書くのが大変 → スキルが設定の形に整えて渡し、参加者は文そのものだけに集中する
- 日本語入力中の実行で違和感 → 挿入は確定済みの文字列だけなので影響なし、と一言添える

## 見せ合いのポイント
定型句の中身が完全に人それぞれ。「その文、自分も使う」という共感と、その人の仕事ぶりが見えるのが面白い。
