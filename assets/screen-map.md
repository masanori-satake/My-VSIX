# 画面マップ: 「どこに出したいか」を指差しで決めるための図

`screen-map.svg` が VS Code の画面を領域ごとに番号で分けた図です。my-vsix-shape では、この図の番号か、下の日常の言葉で答えてもらいます。専門用語を覚える必要はありません（用語への置き換えは AI が裏で行います）。

## 領域の一覧

| 番号 | 日常の言葉 | 裏側の用語 | 使う型 |
|---|---|---|---|
| 1 | 上の帯 | タイトルバー／メニューバー | （直接は使わない） |
| 2 | 左端の細い帯 | アクティビティバー | 一覧の切り替え入口として |
| 3 | 左の一覧 | サイドバー（エクスプローラ／ツリービュー） | 一覧を常時見せたい場合 |
| 4 | 真ん中の本文 | エディタ | 編集の対象そのもの |
| 5 | 右側の場所 | セカンダリサイドバー | 補助情報の常設先として |
| 6 | 下の広い部分 | パネル（出力／端末など） | ログや結果の表示先として |
| 7 | 一番下の細い帯 | ステータスバー | 表示型の主表示先（いつも目に入る） |
| 8 | 呼び出し窓 | コマンドパレット | コマンド型の入口 |
| 9 | 大きな窓 | Webview パネル（エディタ領域に開く） | パネル型の表示先 |

## 使い方（スキル向け）
- 「どこで見たいか」を聞くときは、この図を見せて番号か言葉で答えてもらう
- 答えは `term-bridge.md` の対訳表で具体的な配置先に翻訳し、型ごとの API 許可リストと照合する
- 最終確認はプレビューで行う（この図自体は「場所の合意」のためのもので、見た目の確認は make のプレビューの仕事）
